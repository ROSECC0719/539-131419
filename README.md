# 539 收藏分析 Pro Ultimate V5.1｜雙模型研究版

## V5.1 新增
- 模型 A：原 AI 綜合研究（收藏規則、三碼對照、歷史下期驗證、近期牌路）。
- 模型 B：相似期回溯。以最新 5 碼搜尋歷史至少重複 2 碼的期數，取當時其餘伴隨號，再過濾最近 12 期已開號碼，列出最多 5 碼研究參考。
- 雙模型交集：A/B 同時出現時另外標示，但兩組不混在一起。
- 資料設定新增「補齊 11/25～最新落球資料」，依公開資料的落球順序匯入，既有日期不覆蓋。
- 保留 V5.0 離線快取、Firebase 跨裝置同步、紙本模式、位置規則。
