# 539 收藏分析 Pro Ultimate V5.0

## 功能
- Firebase Email/Password 登入
- Firestore 手機、電腦即時同步
- 開獎日期補登與開出順序保存
- 01～39 逐號三碼對照
- 下一期開出時自動圈選上一期命中候選
- 紙本表格模式
- 收藏規則追蹤、到期與達標判斷
- 規則管理、JSON 備份、CSV 匯出
- V3 localStorage 舊資料一鍵搬移到雲端

## GitHub Pages 更新
把 index.html、manifest.webmanifest、service-worker.js 上傳覆蓋原檔並 Commit。

## Firestore 安全規則（重要）
Firebase Console → Firestore → 規則，貼上 firestore.rules 的內容並發布。
規則只允許登入者讀寫自己的 users/{uid} 資料。

## 使用
第一次開啟可建立帳號。手機與電腦使用同一 Email/密碼登入即可同步。


## V5.0 更新
- 規則管理依「觸發號碼」由小到大排序。
- 新增或修改規則後，顯示順序不再受建立/更新時間影響。
- 多觸發規則以最小觸發號碼為主要排序依據。


## V5.0 新增
- 收藏規則可指定實際開出位置（第1～第5顆）。
- 可選「任一號碼符合」或「全部號碼都要符合」。
- 例如 `35=5`：35 必須第5顆才觸發。
- 例如 `02=1/2、08=1/2` + 全部符合：02、08 必須同時出現在前兩顆，順序可互換。
- 舊規則名稱含「順五」或「順一順二」時會自動推斷位置條件，仍建議進規則管理確認一次。


## V5.0 新增
- 離線版路：已登入並至少在線開啟過一次後，可離線查看最後同步的紙本模式、歷史紀錄與收藏追蹤。離線修改先存在本機，恢復網路後再同步。
- AI 綜合研究建議：每日依最新一期資料產生 5 碼研究排序，結合三碼對照、收藏版追蹤、歷史下一期驗證、近期牌路與多訊號交叉，不只看重複號。
- 注意：建議分數是資料研究排序，不是實際中獎機率；539 每期開獎仍屬隨機。
