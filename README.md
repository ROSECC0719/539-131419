# 539 收藏分析 Pro Ultimate V6.9.2

## AI 自動回測選模版
- AI 不再固定單一權重；每次以歷史 walk-forward 回測比較 8 組候選配方。
- 目前模型依「核心6碼平均命中」與「不出10碼誤中」的綜合目標自動選擇。
- 顯示核心6碼的隨機基準（約 0.77 碼/期）。
- 顯示不出10碼的隨機基準（約 87.18%）、超額表現與平均每期誤中碼數。
- 最近30期回測每一期都只使用當期之前資料，避免資料穿越。

研究統計不等於未來中獎機率。


## V6.9.2 更新

- 規則歷史回補：新增／修改規則後，立即以全部既有開獎資料重算過去觸發與命中。
- 規則管理新增「重算全部規則」，可隨時重新建立排行榜、收藏追蹤與紙本規則結果。
- 每條規則顯示歷史觸發、已結束、達標、追蹤中與命中率摘要。
- 刪除規則後同步重新整理歷史統計。

- 手機底部導覽新增 AI研究與「更多」，完整保留命中統計、尾數版路覆蓋、規則管理等入口。
- AI 改為短5期／短10期／中30期動態權重，加上近期衰減共開關聯與回歸訊號。
- 新增與上一期模型比較：續留、新進、退出與新進原因。
- 不強迫每期換號，仍以 walk-forward 回測選模。


## V6.9.2 順位明示修正

- 紙本模式新增「順位」欄，明確顯示第1顆～第5顆，避免把對照號欄位誤認成開獎順位。
- 若觸發號碼有開出、但不符合位置條件，收藏版會顯示「未觸發」原因。
- 例如規則 `02=1`：只有 02 為當期第1顆才觸發；若 02 在第2顆或第3顆，會明確標註位置不符。
- 規則運算本身維持嚴格順位判定，不會為了歷史回補而放寬條件。


## V6.9.2 順球順位修正
- 收藏規則的「位置 1～5」改為順球順位：將當期 5 個號碼由小到大排序後判斷。
- 紙本模式仍保留原始落球先後，不會把紙本資料改成排序資料。
- 例：29、22、02、04、25 的順球為 02、04、22、25、29，因此規則 `02=1` 會觸發。
- 新增／修改規則後的歷史回補、收藏追蹤、命中排行榜與紙本規則顯示全部共用同一套順球規則引擎。
