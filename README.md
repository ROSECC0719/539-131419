# 539 Pro Ultimate V6.27.32｜星期熱號獨立分頁版

- 保留 V6.27.30 每日鎖榜與歷史快照，以及全部既有功能。
- 「順位補接研究」新增「星期熱號 TOP5」：星期一～星期六各自統計 01～39 歷史出現次數，列出每個星期最常開的 5 個號碼。
- 支援近1年／近2年／近3年／近5年切換，各視窗依最新研究資料日期往回切。
- 每顆顯示開出次數、該星期有效樣本期數與歷史出現率。
- 同一號碼若同時進入該星期多個年度視窗 TOP5，顯示「多窗重疊」標記。
- 此功能為歷史頻率研究，不代表未來中獎機率。

- 電腦版與手機更多選單皆可直接進入。
