# 539 收藏分析系統 V2.0

可直接部署到 GitHub Pages 的靜態網站。

## 功能
- 539 本期號碼自動對照
- 收藏規則自動觸發與期數追蹤
- 可自行新增、修改、刪除收藏規則
- 歷史紀錄、JSON 備份還原、CSV 匯出
- 手機主畫面安裝與離線快取

## GitHub Pages
將此資料夾內的 `index.html`、`manifest.webmanifest`、`service-worker.js`、`README.md` 上傳到 Repository 根目錄，再到 Settings → Pages，選擇 Deploy from a branch、main、/(root)。

資料存放於使用者目前的瀏覽器；更換手機或清除瀏覽資料前，請先匯出 JSON 備份。
