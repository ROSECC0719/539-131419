# V6.27.28 怪牌反向研究｜近五年逐期回測

新增「牌路研究 → 怪牌反向研究」（手機更多也有）。

- 連莊：當期與前期至少一碼相同，從該期之後的下一期驗證。
- 三顆同尾：當期同一尾至少三碼，從下一期驗證。
- 反向與順勢各選5碼，以當期以前最多156期頻率排名。為維持5碼，順勢候選不足時以其餘高頻號補滿。
- 僅計算有效相鄰開獎期（日期間隔1～4天），且樣本當期落在最新日期往回完整5年。
- 顯示事件樣本數、兩邊平均命中碼數、2碼以上比例、下一期結構持續率、最近80次可逐筆展開核對。
- 僅最新一期符合條件時展示當下候選，不預填未來結果。
- 保留前版所有原始功能與正式雲端資料；本研究只讀既有歷史來源，不寫入資料庫。
- 歷史成績不是未來中獎機率，兩種策略均沒有保證優勢。
