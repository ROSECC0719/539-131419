# 539 Pro Ultimate V6.26.8

## V6.26.8｜首頁 TOP3 上週號碼版
- 今日作戰首頁「本週順位 TOP3｜近1年」保留每週一結算的近1年 30 組排名。
- TOP3 每張卡新增「上週號碼」：依該名次的星期與順位，自動抓取上週最近一次該星期的實際順位號碼。
- 例如「星期六・順1」會顯示上週星期六的順1實際號碼；星期四、星期五等依此類推，不寫死號碼。
- 順球模式使用每期小到大排序後的順位；落球模式使用原始開出先後順位。
- 首頁週榜仍於每週一換榜，週內固定；保留命中週數、有效週數與歷史下週重現率。
- 修正首頁資料截止日改用本地日期格式，避免 UTC 日期偏移。

歷史統計僅描述既有資料，不代表未來中獎機率。
