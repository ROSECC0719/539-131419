# 539 Pro Ultimate V6.27.30｜每日鎖榜與歷史快照

- 每個開獎日期的 5 碼分析，在儲存後建立固定快照：原收藏 MAP、歷史下期 TOP3、各來源樣本數與次數、收藏 MAP 的 TOP20 排名。
- 鎖榜存於 Firestore `users/{uid}/dailyRankLocks/{YYYY-MM-DD}`，與主 history 分離；本機另有使用者專屬快取。
- 同一日期、同組 5 碼重新分析優先讀原雲端快照，無雲端連線時可讀本機快照。
- 「本期分析」可手動讀取鎖榜，或在確認後手動重算覆蓋；不自動改寫舊榜。
- 「歷史下期 TOP3」獨立頁仍是會隨資料變動的即時全期間研究表，和固定的每日榜單不同。
- 保留其他既有功能。若 Firestore 安全規則未授權新 dailyRankLocks 路徑，雲端鎖榜會失敗，請確認 Firebase 規則；應以雲端成功狀態作為跨裝置保證。
