# 539 收藏分析 Pro Ultimate V6.18｜AI 純數據自校準版

本版重做 AI週牌與 AI逆向研究：

- 完全移除老師牌、人工訊號與舊的固定日期衰減。
- 只使用正式歷史開獎、近期頻率、遺漏回歸、跨期轉移、三碼對照、收藏規則。
- 每個訊號都先做 walk-forward 前推回測，再依歷史可靠度動態加權。
- AI逆向研究顯示核心6碼、獨支研究、車碼、4柱、01～39排行與最近24期前推結果。
- 「不出10碼」只有在歷史前推明顯優於同碼數隨機基準時才顯示，否則主動不推薦。
- AI週牌改成全週核心6碼 + 週一至週六每日2～3碼，由日別歷史與整體模型投票產生。
- 不再顯示假性的 90%+ 信心機率，改顯示前推平均命中、隨機基準、至少中1比例與穩定度。
- 保留 V6.16.3 所有既有功能與紙本五格均分。

注意：今彩539每期開獎具有隨機性。這些統計只能改善模型的回測紀律與篩選方式，不能保證提高實際中獎機率。
