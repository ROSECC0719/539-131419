# 539 收藏分析 Pro Ultimate V6.5

GitHub Pages 專用版本。

## V6.5 變更
- 「拖牌統計」改為獨立分頁，不再塞在命中統計底部。
- 拖牌頁順序調整為：① 本期開出數字拖牌重點；② 01～39 全號碼拖牌統計。
- 新增「01～39 全號碼拖牌統計」：每個來源號碼統計下一期最常出現的號碼與尾數，保留命中次數 / 樣本數 / 歷史跟隨率。
- 新增「本期開出數字拖牌重點」：自動針對最新一期 5 顆分別計算，並整理至少被 2 個本期號碼同時帶到的交叉拖牌。
- 本期拖牌統計只使用最新一期以前的歷史資料，避免把未來資料倒灌進當期研究。
- 可篩選來源最低樣本數（不限、≥5、≥10、≥20、≥30），並切換每號顯示 Top 3 / Top 5 / Top 10。
- 模型 B 維持近 10 期觀察；模型 A、智慧模型 C、AB、ABC、每日研究存檔、歷史回補與原命中統計全部保留。
- 「每日研究存檔」的「最近 12 期」顯示範圍不變；這與模型 B 的 10 期判斷是兩件不同的設定。
