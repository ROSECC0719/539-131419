# 539 收藏分析 Pro Ultimate V6.16.1｜總覽紙本逐碼透視版

本版延續 V6.15 的「規則逐碼命中透視」，再把相同資訊同步到兩個最常看的地方：

- 總覽 → 進行中的追蹤：每條規則直接顯示「最常開」逐碼排名、命中樣本比例、平均第幾期出現、重複出現總次數。
- 紙本模式 → 收藏版：每條觸發規則下方直接顯示相同逐碼統計，免切換到命中統計頁。
- 帶牌、防牌若有設定，也會分層顯示各自的常開號碼統計。
- 原 V6.15 命中統計、規則管理、TOP20 動態標示、手機/電腦導覽與既有資料邏輯完整保留。

注意：歷史統計僅反映現有資料與規則回測結果，不代表真實開獎機率。


V6.16.1 效能修正：規則歷史回測、逐碼命中統計與 TOP20 對照改用共享快取；只有歷史資料或規則變動時才重新計算，避免總覽／紙本／命中統計反覆掃描全部歷史造成手機或瀏覽器無回應。
