# 539 Pro Ultimate V6.23.1

本版新增「交集星級研究」：依近期5期、4～6期未開、遠星/7～10期、近20期熱號等條件建立候選池，使用最近約3個月歷史逐期檢查下一期命中星數，並加入星期五奇偶型態統計。為避免手機死機，星級研究採手動載入，不在切頁時自動執行。保留 V6.19.9 全部既有功能與 Firebase 相容性。


V6.21.1: 星級研究修正「＋」為候選池合併；新增全歷史/1年/半年/3個月視窗與整合抓牌排序、單雙分組。

V6.21.1: 星期奇偶型態由只看星期五，擴充為星期一至星期六；各日顯示樣本、六種奇偶比例、主/次型態，並自動標記下一期星期。

V6.21.1: 每日智慧配牌升級為多來源總評，正式納入紙本對照TOP20、尾頭首選、三模型A/B/C與規則雷達；星期奇偶只負責最後5碼結構。

V6.21.1: 更正遠星定義為遺漏11期以上（含16～19期）；未開期數表新增固定圖例：近期0–3、觀察4–10、遠星11+。


## V6.21.1
- 規則管理新增「連莊」觸發器，可設定連續2～10期。
- 新增總和值分層研究，智慧配牌優先參考歷史常見總和值區。
- AI逆向研究改為多視窗自適應研究說明：30/60/120期 Walk-forward、近期失效降權、星期奇偶與總和值約束。
- 遠星維持 11期以上。

## V6.21.2
- GPT 原生抓號升級為多尺度轉態、個體 interval hazard、條件轉移、相似局勢四來源共識。
- 仍完全不讀規則管理、拖牌、MAP/TOP20、尾數、三模型、AI週牌、規則雷達、好朋友牌或抓號分層。
- 新增 GPT 每日牌路紀錄：每天第一次主組自動保留，同日重算不覆蓋；開獎資料補入後自動核對星數。
- 每日紀錄使用獨立 localStorage，登入時另備份至 users/{uid}/gptNativeDaily/{date}，不混入正式 history。
- Walk-forward 維持嚴格只看過去，不以未來資料美化回測；歷史成績不代表未來中獎率。

## V6.22.7 雲端安全修復

- permission-denied 時禁止用空白 state 建立/覆寫 main，避免 0 期誤寫回雲端。
- 主資料錯誤訊息獨立顯示，附加研究模組失敗不再影響正式 history。

## V6.22.7
- 新增「歷史牌勢驗牌器」獨立分頁：可輸入連碰號碼或 2～10 柱實際號碼，依歷史多尺度轉態、遺漏節奏、跨期與星期結構顯示牌勢支持度、單號排行、分柱強弱及近20/60/120期落點統計。牌勢％為模型支持度，不宣稱為真實中獎機率。
