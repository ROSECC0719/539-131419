# 539 收藏分析 Pro Ultimate V6.9.8

## 雙驗證模式修正版

- 收藏規則新增「驗證方式」：N期內（第1～N期）／指定下N期（只驗證第N期）。
- 舊規則預設維持 N期內，避免改變既有回測語意。
- 指定下N期的前 N-1 期完全不計命中或未中，只在第 N 期驗證。
- 收藏追蹤、歷史回補與 AI 規則加權同步使用相同驗證語意。
- 保留 V6.9.6 的 114 年度起完整落球資料補齊功能與順球順位判定。

## 114年度起完整落球資料版

本版沿用 V6.9.5 全部功能，新增／修正：

- 「資料設定」可一鍵補齊民國114年（2025-01-01）到最新一期。
- 使用台灣彩券 Daily539Result API 的 `drawNumberAppear` 作為實際落球順序。
- 已有日期不重複覆蓋，避免破壞既有手動資料。
- 順球順位仍由每期5碼另行由小到大排序後判定，與落球順序分開。
- 補齊後會存入 Firebase，手機與電腦登入同一帳號即可同步。

## 使用

更新 GitHub 後登入網站，進入「資料設定」→「從台彩補齊 114/01/01～最新落球資料」。
等待完成訊息即可。

## V6.10 主牌／帶牌／防牌回測
- 收藏規則新增「帶牌」與「防牌」欄位；主牌維持正式達標判定。
- 歷史回測分開顯示主牌達標率、帶牌命中率、防牌命中率與任一層命中率。
- 舊規則完全相容：沒有帶牌／防牌的規則照原本方式計算。
- 範例：19開 2期內 02、12、22 帶 25、35 防 32：主牌填 02、12、22；帶牌填 25、35；防牌填 32。

## V6.11 動態 TOP20 收藏標記
- 命中統計排行榜與紙本模式收藏版共用同一套動態排名。
- TOP 3 / TOP 10 / TOP 20 以不同底色與圖示標記。
