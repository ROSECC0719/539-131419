# 539 Pro Ultimate V6.20.5

本版新增「交集星級研究」：依近期5期、4～6期未開、遠星/7～10期、近20期熱號等條件建立候選池，使用最近約3個月歷史逐期檢查下一期命中星數，並加入星期五奇偶型態統計。為避免手機死機，星級研究採手動載入，不在切頁時自動執行。保留 V6.19.9 全部既有功能與 Firebase 相容性。


V6.20.5: 星級研究修正「＋」為候選池合併；新增全歷史/1年/半年/3個月視窗與整合抓牌排序、單雙分組。

V6.20.5: 星期奇偶型態由只看星期五，擴充為星期一至星期六；各日顯示樣本、六種奇偶比例、主/次型態，並自動標記下一期星期。

V6.20.5: 每日智慧配牌升級為多來源總評，正式納入紙本對照TOP20、尾頭首選、三模型A/B/C與規則雷達；星期奇偶只負責最後5碼結構。
