# 539 收藏分析 Pro Ultimate V5.6｜完整命中統計＋ROSE品牌版

## 本次進化

- 模型 B 改為「全量交叉比對」：2025-11-25 起所有歷史期都與最新一期逐期比對。
- 只要重複至少 2 碼就全部列出，不再只顯示前 8 組。
- 明細先依重複碼數（4→3→2）排序，再依日期由新到舊。
- 顯示重複 2 / 3 / 4 / 5 碼各有幾組，方便和紙本逐筆核對。
- 模型 B 的伴隨次數改由「全部符合歷史期」統計，再套近 12 期未開條件，最後仍提供最多 5 碼研究建議。
- 模型 A、雙模型交集、Firebase 同步、離線快取、台彩歷史補齊均保留。

## 更新方式

將 ZIP 內所有檔案上傳 GitHub Repository 覆蓋舊版，再 Commit changes。首次開啟建議強制重新整理一次。


## V5.3 收藏逐期驗證
- 收藏規則只看觸發日之後的有效期數。
- 有效期內個別牌支開出會紅圈並標示實際命中日期。
- 到期仍沒開的個別牌支標示 ×；未走完期數則顯示追蹤中。
- 規則整體是否達標仍依「單期至少命中」門檻判斷。

## V5.4 紙本雙向排序
- 紙本模式預設「最新優先」，最新一期直接顯示在最上方。
- 可一鍵切換「最新優先 / 最舊優先」，選擇會保存在本機。
- 僅改畫面顯示順序；開獎時間軸、下一期圈選、收藏規則有效期與命中判定仍使用原始日期正序計算。


## V5.6 AB 綜合加權版
- 保留模型 A、模型 B 與原本的雙模型交集。
- 新增「AB 綜合研究版」：A、B 全部候選先標準化，再以 A 60% + B 40% 融合排序。
- 綜合版不是只挑交集；A-only 或 B-only 的強訊號也能入選 Top 5。
- 複製建議會同時帶出 A、B、AB 綜合與雙模型交集。
